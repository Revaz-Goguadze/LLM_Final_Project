# MVP Roadmap

## Phase 1: Foundations
- Git diff ingestion
- Codebase indexing (basic chunking)
- Primary RAG retrieval

## Phase 2: Multi-Model Analysis
- Integrate Gemini + OpenRouter models
- Standardized report schema
- Aggregation and ranking

## Phase 3: Secondary RAG
- Add framework docs (React, etc.)
- Context merging and token budgeting

## Phase 4: Evaluation
- Test dataset runner
- Metrics dashboard
- Model selection and tuning

## Phase 5: Fix Loop
- GenerateFix -> ApplyFix -> Verify
- Retry logic + failure reporting
